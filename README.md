📸 Field Survey Report System (現勘調查報告系統)
A simple web tool to turn GPS photos into map points and professional PDF reports.
一個將帶有座標的照片自動轉化為地圖點位，並快速產出專業現勘報表的網頁工具。
✨ Features (功能特色)
Auto-Mapping: Reads GPS, time, and direction from photos. (自動讀取照片座標、時間、拍攝方位)
Manual Edit: Drag markers to fix GPS offsets and add field notes. (支援拖曳點位修正座標，並可輸入現勘筆記)
Smart Report: Generates a professional PDF report (4 photos per page). (一鍵產生 PDF 報表，每頁自動排列 4 張照片)
100% Private: Photos stay on your device; nothing is uploaded to servers. (100% 隱私保護，照片僅在本地處理，不會上傳至伺服器)
🚀 How to Use (使用方式)
Import: Click "Import Photos" and select images with GPS. (點擊「匯入照片」，選擇帶有座標的照片)
Edit: Drag markers to correct locations or click to add notes. (拖曳點位校正位置，或點選點位輸入筆記)
Export: Click "Generate Report" and save as PDF. (點擊「產生現勘報告」並另存為 PDF)
